# fTetWild fallback tier (--experimental-fallback-ftetwild).
# Installed by DEFAULT on Linux (install.sh), macOS (install-macos.sh) and in
# the AppImage, into the main Sutura environment. Opt out with
# SUTURA_WITH_FTETWILD=0; if the install fails the tier is disabled with a
# warning and the rest of Sutura is unaffected.
#
# (FAZ17) pytetwild is the pybind11/nanobind wrapper for fTetWild (MPL-2.0,
# compatible with our PolyForm-Noncommercial license). It is invoked as a
# subprocess bridge (sutura/ftetwild_bridge.py) by repair.py behind
# --experimental-fallback-ftetwild.
#
# Only pytetwild is listed. pytetwild's __init__ imports its PyVista accessor
# unconditionally, but the bridge stubs that accessor out before importing (the
# API used, pytetwild.tetrahedralize on numpy arrays, never touches PyVista), so
# PyVista/VTK (~520 MB) are deliberately NOT pulled in.
pytetwild==0.4.2
